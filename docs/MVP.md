# WBIA MVP

## Outcome
Run a real customer request end-to-end through WBIA while WBIA retains the customer relationship.

## Initial service wedge
- Auto glass
- Auto mechanics
- Auto body
- Construction

## Operating flow
Request -> triage/scope -> provider bid(s) -> provider selection -> WBIA customer quote -> approval/payment -> dispatch -> completion -> provider payout -> margin recorded.

## Next build slices
1. Persist customer requests and job photos.
2. Operations dashboard: request queue and job status.
3. Provider registry: services, coverage, availability, credentials and warranty terms.
4. Bid collection and comparison.
5. Quote builder with provider cost, customer price and gross margin.
6. Dispatch/status workflow.
7. Payment and payout integration after the commercial/legal structure is confirmed.

## Provider bench captured at kickoff
Initial network includes auto services through R&R plus painters, construction providers, cleaning companies, detailers and software engineers. Coverage is initially Greater Boston / surrounding Massachusetts communities, with service area ultimately configured per provider.

## Product principle
The public experience is not a directory. The front door is: **What do you need done?** WBIA coordinates fulfillment behind the scenes.
